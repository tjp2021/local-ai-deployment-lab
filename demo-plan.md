# Demo Plan

Target length: two minutes.

1. State the deployment question in one sentence.
2. Show the same synthetic incident manifest used by both adapters.
3. Run one local inference on a physical phone with network status visible.
4. Show one valid structured result and one failure or constraint.
5. Show the deterministic router recording zero cloud calls for a restricted case.
6. Show the normalized result record and device/runtime metadata.
7. End with the deployment recommendation and the upstream issue, test, documentation contribution, or maintainer validation.

Do not open with company history, a résumé pitch, or a dashboard tour. Do not claim that a two-minute demo proves production readiness.
