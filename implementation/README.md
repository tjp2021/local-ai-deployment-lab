# Implementation

The validated implementation now contains:

- runtime-neutral case, model-output, native-generation, and result contracts;
- eighteen synthetic incident fixtures;
- a deterministic routing gate with a zero-network cloud spy;
- a QVAC 0.15.0 adapter using native JSON Schema constraints plus independent validation;
- an ExecuTorch 1.3.1 harness adapter with a versioned native bridge boundary.

Adapter contract tests are not physical-device evidence. Native apps, model artifacts, and raw device results land only after their exact dependency, storage, signing, and device requirements are verified.
